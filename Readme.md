# SplitMate

A web application for managing shared expenses.

## Features
- Group management
- Member management
- Shared expenses
- Balance calculation
- Reimbursements
- Search, filters and sorting
- Dashboard
- LocalStorage persistence

## Technologies
- HTML5
- CSS3
- Bootstrap 5 or Tailwind CSS
- JavaScript ES6+
- Git and GitHub
